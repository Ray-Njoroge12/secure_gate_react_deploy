# Data Retention Policy

**Secure Gate Access Control System**  
**Effective Date:** October 11, 2025  
**Version:** 1.0  
**Compliance:** Kenya Data Protection Act 2019

---

## 1. Purpose and Scope

This Data Retention Policy establishes guidelines for the retention, storage, and disposal of personal data collected by the Secure Gate Access Control System in compliance with Kenya Data Protection Act 2019.

### 1.1 Objectives
- Ensure compliance with legal and regulatory requirements
- Minimize data retention to necessary periods only
- Protect individual privacy rights
- Maintain data security and integrity
- Enable effective business operations

### 1.2 Scope
This policy applies to all personal data collected, processed, and stored by the Secure Gate Access Control System, including data from users, visitors, and system operations.

---

## 2. Legal Framework

### 2.1 Kenya Data Protection Act 2019
- **Article 33**: Data retention limitation principle
- **Article 34**: Storage limitation
- **Article 35**: Purpose limitation

### 2.2 Other Applicable Laws
- Employment Act (for employee data)
- Companies Act (for business records)
- Tax laws (for financial records)
- Security regulations (for access logs)

## 3. Data Categories and Retention Periods

### 3.1 User Account Data
**Data Type:** Personal information of registered users (residents, guards, administrators)  
**Retention Period:** 7 years from account closure or last activity  
**Legal Basis:** Employment records, contractual necessity  
**Disposal Method:** Secure deletion with audit trail

**Included Data:**
- Full name and username
- Email address and phone number
- Role and permissions
- Account creation and last login dates
- Profile updates and changes

### 3.2 Visitor Data
**Data Type:** Personal information of visitors  
**Retention Period:** 5 years from visit date  
**Legal Basis:** Security and access control, legitimate interest  
**Disposal Method:** Secure deletion with audit trail

**Included Data:**
- Visitor name and contact information
- Visit purpose and duration
- Access times and locations
- QR codes and access passes
- Check-in/check-out records

### 3.3 Access Logs
**Data Type:** System access and security logs  
**Retention Period:** 7 years from log creation  
**Legal Basis:** Security monitoring, legal obligation  
**Disposal Method:** Secure deletion with audit trail

**Included Data:**
- User authentication events
- System access attempts
- Security incidents and alerts
- Failed login attempts
- System configuration changes

### 3.4 Audit Logs
**Data Type:** System audit and compliance logs  
**Retention Period:** 7 years from log creation  
**Legal Basis:** Compliance requirements, legal obligation  
**Disposal Method:** Secure deletion with audit trail

**Included Data:**
- Data subject rights requests
- Consent management events
- Data processing activities
- Security events and incidents
- Compliance monitoring records

### 3.5 Consent Records
**Data Type:** User consent and withdrawal records  
**Retention Period:** 3 years from consent withdrawal or expiry  
**Legal Basis:** Consent management, legal requirement  
**Disposal Method:** Secure deletion with audit trail

**Included Data:**
- Consent given timestamps
- Consent types and purposes
- Withdrawal requests and dates
- Consent version information
- IP addresses and user agents

### 3.6 Data Subject Access Requests (DSAR)
**Data Type:** Data subject rights request records  
**Retention Period:** 7 years from request completion  
**Legal Basis:** Legal obligation, audit requirements  
**Disposal Method:** Secure deletion with audit trail

**Included Data:**
- Request details and types
- Processing status and outcomes
- Response data and timestamps
- Requestor identification
- Resolution documentation

## 4. Data Retention Schedule

### 4.1 Active Data (0-1 year)
- Current user accounts
- Recent visitor records
- Active access logs
- Recent audit events

### 4.2 Archive Data (1-5 years)
- Closed user accounts
- Completed visitor visits
- Historical access logs
- Archived audit events

### 4.3 Long-term Retention (5-7 years)
- Legal requirement data
- Compliance records
- Employment records
- Security incident data

### 4.4 Disposal Schedule
- **Monthly Review:** Automated review of data eligible for disposal
- **Quarterly Disposal:** Secure deletion of expired data
- **Annual Audit:** Comprehensive review of retention compliance

---

## 5. Data Storage and Security

### 5.1 Storage Locations
- **Primary Storage:** Encrypted database with access controls
- **Backup Storage:** Encrypted backups with separate access controls
- **Archive Storage:** Encrypted long-term storage with restricted access

### 5.2 Security Measures
- **Encryption:** All data encrypted at rest and in transit
- **Access Controls:** Role-based access with audit logging
- **Backup Security:** Encrypted backups with secure key management
- **Physical Security:** Secure data centers with access controls

### 5.3 Data Integrity
- **Checksums:** Data integrity verification
- **Audit Trails:** Complete audit logging of all data operations
- **Version Control:** Data versioning and change tracking
- **Recovery Testing:** Regular backup and recovery testing

---

## 6. Data Disposal Procedures

### 6.1 Disposal Criteria
- Data exceeds retention period
- Consent withdrawn and no legal basis remains
- Data subject requests deletion
- Legal obligation fulfilled

### 6.2 Disposal Methods
- **Secure Deletion:** Cryptographic erasure of data
- **Physical Destruction:** Secure destruction of physical media
- **Audit Trail:** Complete documentation of disposal process
- **Verification:** Confirmation of successful disposal

### 6.3 Disposal Process
1. **Identification:** Identify data eligible for disposal
2. **Review:** Legal and business review of disposal decision
3. **Approval:** Management approval for disposal
4. **Execution:** Secure disposal of data
5. **Verification:** Confirmation of disposal completion
6. **Documentation:** Record disposal in audit trail

---

## 7. Special Circumstances

### 7.1 Legal Holds
- **Litigation Hold:** Suspend disposal during legal proceedings
- **Regulatory Investigation:** Retain data during investigations
- **Court Orders:** Comply with court-ordered data retention
- **Documentation:** Maintain records of legal holds

### 7.2 Data Subject Rights
- **Right to Erasure:** Honor valid deletion requests
- **Right to Rectification:** Update incorrect data promptly
- **Right to Portability:** Provide data in portable format
- **Right to Restrict:** Limit processing when requested

### 7.3 Business Continuity
- **Disaster Recovery:** Maintain data for business continuity
- **Historical Analysis:** Retain data for trend analysis
- **Compliance Reporting:** Maintain data for regulatory reporting
- **Audit Requirements:** Retain data for internal and external audits
