## 🔧 Troubleshooting Common Issues

### Mobile Browser Issues
**Problem**: Interface looks broken on mobile
**Solution**: 
1. Clear browser cache
2. Update to latest browser version
3. Try landscape orientation for forms

**Problem**: QR scanner not working
**Solution**:
1. Allow camera permissions in browser
2. Ensure adequate lighting
3. Clean camera lens

### Desktop Browser Issues
**Problem**: Layout appears cramped
**Solution**:
1. Zoom out (Ctrl + -) if too large
2. Maximize browser window
3. Clear browser cache

**Problem**: Keyboard shortcuts not working
**Solution**:
1. Check browser extensions aren't blocking shortcuts
2. Try refreshing the page
3. Ensure browser window is focused

### General Performance Issues
**Problem**: Slow loading times
**Solution**:
1. Check internet connection
2. Clear browser cache and cookies
3. Close unnecessary browser tabs
4. Contact system administrator if persistent
