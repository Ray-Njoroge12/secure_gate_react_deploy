⏳ BACKEND DEPLOYMENT - COMPLETE THESE STEPS
================================================================================

1. Go to Render Dashboard: https://dashboard.render.com/

2. Click "New +" → "Blueprint"

3. Connect GitHub Repository:
   - Repository: Ray-Njoroge12/secure_gate_react_deploy
   - Branch: main

4. Render will detect render.yaml automatically

5. Configure Required Secrets (⚠️ IMPORTANT):

   DATABASE (Auto-created by Render):
   - PGHOST - from Render PostgreSQL
   - PGPORT - from Render PostgreSQL  
   - PGDATABASE - from Render PostgreSQL
   - PGUSER - from Render PostgreSQL
   - PGPASSWORD - from Render PostgreSQL

   REDIS (Add Render Redis addon):
   - REDIS_URL - from Render Redis

   SECURITY (Generate new values):
   - JWT_SECRET - use: openssl rand -hex 32
   - JWT_REFRESH_SECRET - use: openssl rand -hex 32
   - SESSION_SECRET - use: openssl rand -hex 32

   EXTERNAL SERVICES:
   - AT_API_KEY - Your Africa's Talking API key
   - MAILGUN_API_KEY - Your Mailgun API key

6. Click "Apply" to deploy

7. After deployment, run migrations:
   - Go to Shell tab in Render dashboard
   - Run: npm run db:migrate
   - Run: npm run db:seed

8. Update Frontend API URL if different:
   - Go to Netlify dashboard
   - Update REACT_APP_API_URL with actual Render URL
   - Trigger redeploy
