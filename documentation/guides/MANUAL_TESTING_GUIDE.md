## 📋 Test Scenario 3: Authentication Flow

### A. Get CSRF Token

```bash
curl -i http://localhost:5001/api/auth/csrf-token \
  -H "Origin: http://localhost:3001" \
  -c cookies.txt
```

**Expected Response:**

```json
HTTP/1.1 200 OK
X-CSRF-Token: <token>
Set-Cookie: connect.sid=...

{
  "csrfToken": "<token>"
}
```

Save the CSRF token from the response for later use.

### B. Register a New User

```bash
curl -X POST http://localhost:5001/api/auth/register \
  -H "Content-Type: application/json" \
  -H "Origin: http://localhost:3001" \
  -H "X-Request-ID: register-test-001" \
  -b cookies.txt \
  -d '{
    "email": "testuser@example.com",
    "password": "SecurePass123!",
    "firstName": "Test",
    "lastName": "User",
    "phone": "+254712345678",
    "role": "resident",
    "estate_id": 1
  }'
```

**Expected Response:**

```json
{
  "success": true,
  "message": "Registration successful",
  "user": {
    "id": 1,
    "email": "testuser@example.com",
    "firstName": "Test",
    "lastName": "User",
    "role": "resident"
  },
  "requestId": "register-test-001"
}
```

### C. Login

```bash
curl -X POST http://localhost:5001/api/auth/login \
  -H "Content-Type: application/json" \
  -H "Origin: http://localhost:3001" \
  -H "X-Request-ID: login-test-001" \
  -c cookies.txt \
  -d '{
    "email": "testuser@example.com",
    "password": "SecurePass123!"
  }'
```

**Save the access token from the response!**

### D. Test Protected Endpoint

## 📋 Test Scenario 4: CSRF Protection

### A. POST Without CSRF Token (Should Fail)

```bash
curl -X POST http://localhost:5001/api/visitors \
  -H "Content-Type: application/json" \
  -H "Origin: http://localhost:3001" \
  -H "Authorization: Bearer <ACCESS_TOKEN>" \
  -H "X-Request-ID: csrf-fail-test-001" \
  -d '{
    "firstName": "Jane",
    "lastName": "Doe"
  }'
```

**Expected Response:**

```json
HTTP/1.1 403 Forbidden
X-Request-ID: csrf-fail-test-001

{
  "error": {
    "message": "CSRF token validation failed",
    "code": "CSRF_INVALID",
    "requestId": "csrf-fail-test-001"
  }
}
```

### B. POST With Valid CSRF Token (Should Succeed)

```bash
# First get a fresh CSRF token
curl http://localhost:5001/api/auth/csrf-token \
  -H "Origin: http://localhost:3001" \
  -b cookies.txt \
  -c cookies.txt

# Then use it in your POST request
curl -X POST http://localhost:5001/api/visitors \
  -H "Content-Type: application/json" \
  -H "Origin: http://localhost:3001" \
  -H "Authorization: Bearer <ACCESS_TOKEN>" \
  -H "X-CSRF-Token: <CSRF_TOKEN>" \
  -H "X-Request-ID: csrf-success-test-001" \
  -b cookies.txt \
  -d '{
    "firstName": "Jane",
    "lastName": "Doe",
    "phone": "+254700000000",
    "idNumber": "12345678",
    "purpose": "Delivery"
  }'
```

## 📋 Test Scenario 5: Estate Context Enforcement

### A. Access Without Estate Context (Should Fail)

```bash
curl -i http://localhost:5001/api/visitors \
  -H "Origin: http://localhost:3001" \
  -H "Authorization: Bearer <ACCESS_TOKEN>" \
  -H "X-Request-ID: no-estate-test-001"
```

**Expected Response:**

```json
HTTP/1.1 403 Forbidden
X-Request-ID: no-estate-test-001

{
  "error": {
    "message": "Estate context required",
    "code": "ESTATE_REQUIRED",
    "requestId": "no-estate-test-001"
  }
}
```

### B. Access With Estate Context (Should Succeed)

```bash
curl http://localhost:5001/api/visitors \
  -H "Origin: http://localhost:3001" \
  -H "Authorization: Bearer <ACCESS_TOKEN>" \
  -H "X-Estate-ID: 1" \
  -H "X-Request-ID: with-estate-test-001"
```

## 📋 Test Scenario 6: Rate Limiting

### A. Rapid Request Test

```bash
# Send 25 requests rapidly
for i in {1..25}; do
  echo "Request $i:"
  curl -i http://localhost:5001/api/health \
    -H "Origin: http://localhost:3001" \
    -H "X-Request-ID: rate-limit-test-$i" \
    2>&1 | grep -E "HTTP|X-RateLimit"
  sleep 0.1
done
```

**Expected:**

- First ~15-20 requests: HTTP 200 OK
- After threshold: HTTP 429 Too Many Requests

### B. Check Rate Limit Headers

```bash
curl -i http://localhost:5001/api/health \
  -H "Origin: http://localhost:3001"
```

**Look for:**

```
X-RateLimit-Limit: 100
X-RateLimit-Remaining: 95
X-RateLimit-Reset: <timestamp>
```

## 📞 Troubleshooting

### Backend Won't Start

```bash
# Check logs
docker-compose -f docker-compose.staging.yml logs backend

# Rebuild
docker-compose -f docker-compose.staging.yml up -d --build backend
```

### CORS Errors

Always include the Origin header:

```bash
-H "Origin: http://localhost:3001"
```

### Authentication Issues

Make sure you:

1. Get a fresh CSRF token
2. Save cookies with `-c cookies.txt`
3. Send cookies with `-b cookies.txt`
4. Include the Authorization header

### Can't Connect

Check if services are running:

```bash
docker-compose -f docker-compose.staging.yml ps
```
