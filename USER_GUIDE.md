## Getting Started

### System Overview

The Secure Gate Access Control System is a comprehensive visitor management solution designed for residential complexes, office buildings, and other secure facilities. The system provides end-to-end visitor management from invitation to check-out.

### Key Features

- **Visitor Management**: Complete visitor lifecycle management
- **QR Code & OTP System**: Secure pass generation and verification
- **Real-time Notifications**: Email and SMS notifications
- **Role-Based Access**: Resident, Guard, Admin, and Visitor roles
- **Mobile-Friendly**: Responsive design for all devices
- **Real-time Updates**: Live dashboard updates

### Supported Browsers

- **Chrome**: 90+
- **Firefox**: 88+
- **Safari**: 14+
- **Edge**: 90+
- **Mobile Browsers**: iOS Safari 14+, Chrome Mobile 90+

### System Requirements

- **Internet Connection**: Required for all operations
- **JavaScript**: Must be enabled
- **Cookies**: Required for session management
- **Camera**: Required for QR code scanning (Guard role)

## Resident Guide

### Getting Started

#### 1. Account Registration
1. Visit the Secure Gate website
2. Click "Register" on the login page
3. Fill in your details:
   - Full Name
   - Email Address
   - Phone Number
   - Password
4. Click "Create Account"
5. Check your email for verification link
6. Click the verification link to activate your account

#### 2. First Login
1. Go to the login page
2. Enter your email and password
3. Click "Sign In"
4. You'll be redirected to your Resident Dashboard

### Dashboard Overview

The Resident Dashboard provides an overview of your visitor management activities:

- **Upcoming Visitors**: Visitors scheduled for today and future dates
- **Recent Visitors**: Visitors from the past week
- **Quick Actions**: Add Visitor, Bulk Invite, Visitor History
- **Notifications**: Real-time updates about visitor activities

### Managing Visitors

#### Adding a Single Visitor

1. **Access Add Visitor**
   - Click "Add Visitor" on the dashboard
   - Or navigate to "Visitors" → "Add Visitor"

2. **Fill Visitor Information**
   - Visitor Name (required)
   - Email Address (required)
   - Phone Number (required)
   - Visit Date (required)
   - Purpose of Visit (required)
   - Additional Notes (optional)

3. **Generate QR Pass**
   - Check "Generate QR Pass Now" if you want immediate access
   - Or leave unchecked to generate later

4. **Submit**
   - Click "Create Visitor"
   - The visitor will receive an email with invitation details

#### Bulk Invitations

1. **Access Bulk Invite**
   - Click "Bulk Invite" on the dashboard
   - Or navigate to "Visitors" → "Bulk Invite"

2. **Upload CSV File**
   - Download the CSV template
   - Fill in visitor details
   - Upload the completed file

3. **Review and Send**
   - Review the imported visitors
   - Make any necessary corrections
   - Click "Send Invitations"

#### Managing Visitor Invitations

1. **View Invitations**
   - Go to "Visitors" → "Invitations"
   - See all pending, sent, and completed invitations

2. **Resend Invitation**
   - Click on an invitation
   - Click "Resend" to send again

3. **Cancel Invitation**
   - Click on an invitation
   - Click "Cancel" to revoke access

### Visitor History

#### Viewing History
1. Navigate to "Visitors" → "History"
2. Use filters to find specific visitors:
   - Date range
   - Visitor name
   - Status (checked in, checked out, expired)

#### Exporting Data
1. Apply desired filters
2. Click "Export" button
3. Choose format (CSV, PDF)
4. Download the file

### Settings

#### Profile Management
1. Click your name in the top-right corner
2. Select "Profile"
3. Update your information:
   - Name
   - Email
   - Phone Number
   - Profile Picture

#### Notification Preferences
1. Go to "Settings" → "Notifications"
2. Configure:
   - Email notifications
   - SMS notifications
   - Push notifications
   - Notification frequency

#### Security Settings
1. Go to "Settings" → "Security"
2. Change password
3. Enable two-factor authentication
4. Manage active sessions

## Guard Guide

### Getting Started

#### 1. Guard Account Setup
1. Contact your administrator to create a guard account
2. You'll receive login credentials via email
3. Log in and change your password

#### 2. First Login
1. Go to the login page
2. Enter your guard credentials
3. Click "Sign In"
4. You'll be redirected to the Guard Dashboard

### Dashboard Overview

The Guard Dashboard provides real-time visitor information:

- **Active Visitors**: Currently checked-in visitors
- **Today's Visitors**: All visitors scheduled for today
- **Quick Actions**: Scan QR, Manual Check-in, Check-out
- **Live Updates**: Real-time notifications

### QR Code Scanning

#### Using the QR Scanner

1. **Access Scanner**
   - Click "Scan QR" on the dashboard
   - Or use the mobile app scanner

2. **Scan Process**
   - Point camera at visitor's QR code
   - Wait for automatic detection
   - Verify visitor details
   - Confirm check-in/check-out

3. **Manual Entry**
   - If scanning fails, click "Manual Entry"
   - Enter QR code manually
   - Or search by visitor name

#### Check-in Process

1. **Scan QR Code**
   - Use scanner to read visitor's QR code
   - System will display visitor information

2. **Verify Details**
   - Confirm visitor name and photo
   - Check visit date and purpose
   - Verify OTP if required

3. **Complete Check-in**
   - Add any notes if needed
   - Click "Check In"
   - Visitor will receive confirmation

#### Check-out Process

1. **Find Visitor**
   - Search for visitor by name
   - Or scan QR code again

2. **Complete Check-out**
   - Add departure notes
   - Click "Check Out"
   - Visitor will receive confirmation

### Manual Operations

#### Manual Check-in
1. Click "Manual Check-in"
2. Search for visitor by name or email
3. Select the correct visitor
4. Complete check-in process

#### Manual Check-out
1. Click "Manual Check-out"
2. Find visitor in active list
3. Complete check-out process

### Visitor Management

#### Viewing Active Visitors
1. Go to "Visitors" → "Active"
2. See all currently checked-in visitors
3. View visitor details and check-in time

#### Searching Visitors
1. Use the search bar
2. Search by:
   - Visitor name
   - Email address
   - Phone number
   - Visit date

#### Visitor Details
1. Click on any visitor
2. View complete information:
   - Personal details
   - Visit purpose
   - Check-in/out times
   - Host information

### Emergency Procedures

#### Emergency Check-out
1. Go to "Emergency" → "Bulk Check-out"
2. Select all visitors
3. Click "Emergency Check-out"
4. Add emergency notes

#### Visitor Issues
1. Report issues through the system
2. Contact administrator if needed
3. Document all incidents

## Visitor Guide

### Getting Started

#### 1. Receiving an Invitation
1. Check your email for invitation
2. Click the invitation link
3. You'll be redirected to the visitor portal

#### 2. Completing Registration
1. Fill in your details:
   - Full Name
   - Email Address
   - Phone Number
   - ID Number (if required)
2. Upload a photo (optional)
3. Click "Complete Registration"

#### 3. Receiving Your Pass
1. After registration, you'll receive:
   - QR code for entry
   - OTP for verification
   - Visit instructions
2. Save the QR code to your phone
3. Note the OTP for entry

### Using Your Pass

#### QR Code
- **Display**: Show the QR code on your phone screen
- **Scanning**: Present to guard for scanning
- **Backup**: Take a screenshot as backup

#### OTP (One-Time Password)
- **Use**: Provide when requested by guard
- **Expiration**: Valid for the visit date only
- **Backup**: Note down the OTP number

### Check-in Process

#### At the Gate
1. **Present QR Code**
   - Show QR code to guard
   - Wait for scanning

2. **Provide OTP**
   - Give OTP when requested
   - Verify your identity

3. **Complete Check-in**
   - Guard will confirm entry
   - You'll receive confirmation

#### Troubleshooting
- **QR Code Not Working**: Ask guard for manual entry
- **OTP Expired**: Contact your host for new pass
- **Wrong Date**: Verify visit date with host

### During Your Visit

#### Visitor Portal
1. **Access Portal**
   - Use the link in your email
   - Or visit the website directly

2. **View Status**
   - Check visit status
   - View check-in time
   - See visit details

#### Check-out Process
1. **At Exit**
   - Present QR code again
   - Guard will check you out
   - You'll receive confirmation

2. **Self Check-out**
   - Use visitor portal
   - Click "Check Out"
   - Confirm departure

## Troubleshooting

### Common Issues

#### Login Problems

**Problem**: Can't log in
**Solutions**:
1. Check email and password
2. Reset password if needed
3. Clear browser cache
4. Try different browser
5. Contact administrator

**Problem**: Account locked
**Solutions**:
1. Wait for lockout period to expire
2. Contact administrator
3. Reset password

#### QR Code Issues

**Problem**: QR code not scanning
**Solutions**:
1. Ensure good lighting
2. Clean camera lens
3. Hold steady
4. Try manual entry
5. Contact guard for assistance

**Problem**: QR code expired
**Solutions**:
1. Check visit date
2. Contact host for new invitation
3. Verify time zone settings

#### Notification Issues

**Problem**: Not receiving notifications
**Solutions**:
1. Check notification settings
2. Verify email address
3. Check spam folder
4. Update contact information
5. Contact administrator

#### Performance Issues

**Problem**: Slow loading
**Solutions**:
1. Check internet connection
2. Clear browser cache
3. Close other tabs
4. Try different browser
5. Restart device

## FAQ

### General Questions

**Q: What is the Secure Gate Access Control System?**
A: It's a comprehensive visitor management solution that allows residents to invite visitors, guards to check them in/out, and administrators to manage the system.

**Q: Who can use the system?**
A: Residents, guards, administrators, and visitors can all use the system with different levels of access.

**Q: Is the system secure?**
A: Yes, the system uses industry-standard security measures including encryption, secure authentication, and audit logging.

**Q: Can I use the system on my phone?**
A: Yes, the system is mobile-friendly and has native apps for iOS and Android.

### Resident Questions

**Q: How do I invite a visitor?**
A: Log in to your dashboard, click "Add Visitor", fill in the details, and send the invitation.

**Q: Can I invite multiple visitors at once?**
A: Yes, use the "Bulk Invite" feature to upload a CSV file with multiple visitors.

**Q: How long are visitor passes valid?**
A: Visitor passes are valid for the specific visit date only.

**Q: Can I cancel a visitor invitation?**
A: Yes, you can cancel invitations that haven't been used yet.

### Guard Questions

**Q: How do I check in a visitor?**
A: Use the QR scanner to scan the visitor's QR code, verify their details, and complete the check-in.

**Q: What if the QR code doesn't scan?**
A: You can use manual entry to search for the visitor by name or enter the QR code manually.

**Q: How do I check out a visitor?**
A: Find the visitor in the active list, scan their QR code again, or search for them manually.

**Q: Can I see all visitors for today?**
A: Yes, the dashboard shows all visitors scheduled for today.

### Visitor Questions

**Q: How do I get a visitor pass?**
A: You'll receive an invitation email from your host with a link to complete registration and get your pass.

**Q: What if I lose my QR code?**
A: Contact your host to resend the invitation or ask the guard for manual entry.

**Q: Can I check myself out?**
A: Yes, you can use the visitor portal or mobile app to check yourself out.

**Q: What if I'm running late?**
A: Contact your host to let them know, or the guard can help with manual entry.

### Technical Questions

**Q: What browsers are supported?**
A: Chrome, Firefox, Safari, and Edge (latest versions) are all supported.

**Q: Do I need to install anything?**
A: No, the system works in your web browser. Mobile apps are optional.

**Q: Is my data secure?**
A: Yes, all data is encrypted and stored securely with regular backups.

**Q: What if the system is down?**
A: Contact your building management or use the emergency contact numbers.

### Admin Questions

**Q: How do I add new users?**
A: Go to "Users" → "Add User" and fill in the user details.

**Q: Can I customize the system?**
A: Yes, you can customize settings, notifications, and branding.

**Q: How do I backup the system?**
A: Go to "Maintenance" → "Backup" to create manual backups or schedule automatic ones.

**Q: Can I view system logs?**
A: Yes, go to "Maintenance" → "Logs" to view system activity and audit trails.
